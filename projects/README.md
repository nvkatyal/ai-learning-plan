# 🧠 AI Learning Plan for Principal Engineer

Welcome to your AI learning journey! This repository contains code, notes, and projects aligned with a 6-month AI learning curriculum focused on LLMs, ML, and full-stack AI system development.

## 📁 Structure

- `projects/` — Projects by phase
- `notebooks/` — Jupyter notebooks
- `data/` — Sample datasets or links
- `scripts/` — Reusable scripts
- `docs/` — Docs, architecture notes

## 🚀 Getting Started

1. Clone this repo
2. Add your code to the relevant `projects/phase-*` folder
3. Use `notebooks/` for experimentation

## 📌 Tip

Use [Weights & Biases](https://wandb.ai), [MLflow](https://mlflow.org), and [Hugging Face Hub](https://huggingface.co) to track models.
